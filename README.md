# computercraft
A library of computercraft scripts.  Currently holds only turtles.
Uses a single script for all downloads and updates.  Bots are then run directly.

## TURTLES
Install the updater once:
```shell
wget https://raw.githubusercontent.com/Kind-Stranger/computercraft/master/getbot.lua getbot.lua
```

Use `getbot` to update it and a bot's libraries:
```shell
getbot <bot>
```
e.g.
```shell
getbot farm
```

After running `getbot`, see the help for an individual bot:
```shell
<bot> help
```


### Available Turtles
- chop
- farm
